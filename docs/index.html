核心能力

不是只会聊天的机器人

从检索、工具调用到事实校验，每一步都能解释。

混合检索 RAG

BM25 与 BGE-M3 向量召回，RRF 融合后由 reranker 精排，取 Top-5 作为生成上下文。

MCP 个人数据

通过独立 MCP Server 查询假期、考勤和部门信息，只读、按工号白名单校验。

事实校验

生成后由 check 节点判断是否 grounded；不通过自动重试一次，仍失败则明确兜底。

多轮会话

Redis checkpoint 按 session_id 保存上下文，支持追问「那病假呢」。

登录与用户表

MySQL users 表 + PBKDF2 密码哈希，登录成功签发 HMAC Token，聊天接口强制鉴权。

流式体验

SSE 逐字输出，引用来源可展开，支持停止生成、失败重试和移动端布局。

界面预览

登录、提问、看引用

蓝白界面，桌面和移动端都可以使用。

工程细节

不只是 Demo 的边界

只读 MCP

不暴露任意 SQL，工号白名单在服务端校验，模型无法越权查询。

审计日志

每次工具调用写入 logs/mcp_audit.jsonl，包含工号、参数和结果状态。

密码哈希

users 表保存 PBKDF2-SHA256 哈希，60 万次迭代，每个账号独立。

不编造答案

资料不足时明确说无法确认，并建议联系 HR，而不是猜测。
